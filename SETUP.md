## 0. What is NOT in the repo (and why everything fails without it)

The following are **gitignored** and must be generated locally on every fresh clone:

| What | Why it's missing | How to get it |
|------|------------------|---------------|
| `data/raw/student_placement.csv` | Kaggle dataset license — not committed | Section 5 below |
| `data/processed/*.csv` | Generated by `preprocessing.py` | Section 6 |
| `venv/` | Virtual environment — machine-specific | Section 3 |
| `part2/models/*.joblib` | `.joblib` globally gitignored + `part2/models/` gitignored | Section 6 + Section 7 |
| `part2/model_results/*` | `part2/model_results/` gitignored | Section 7 |
| `part3/models/*.joblib` | `.joblib` globally gitignored | Section 8 |

The following **are committed** and exist on a fresh clone (no action needed):

| What | Notes |
|------|-------|
| `part3/models/xgboost_best.json` | XGBoost native model format (not `.joblib`, so not gitignored) |
| `part3/model_results/*` (all 10 files) | PNGs + CSVs — committed; re-running `xgboost_model.py` overwrites them |
| `visualizations/*` (14 PNGs) | EDA plots — committed; re-running `visualization.py` overwrites them |

> **Key fact:** without `data/raw/student_placement.csv`, **nothing runs**.
> `preprocessing.py`, `data_analysis.py`, `visualization.py`, and
> `part3/xgboost_model.py` all read from that exact path.

## 1. Prerequisites

### 1a. Python 3.12

Check with:

```bash
python --version        # Windows
python3 --version       # Mac/Linux
```

If you don't have 3.12, install it separately. A venv does **not** fix a
wrong interpreter — you must point venv creation at the correct binary:

```bash
# Windows
py -3.12 -m venv venv

# Mac/Linux
python3.12 -m venv venv
```

### 1b. Kaggle account (free)

`download_dataset.py` uses `kagglehub` which requires a Kaggle account.
**You do NOT need to manually set up API keys.** Just run the script:

```bash
venv\Scripts\python.exe download_dataset.py      # Windows
# venv/bin/python download_dataset.py            # Mac/Linux
```

If no credentials are found, `kagglehub` will **automatically prompt you
in the terminal** with a browser link to log in. Sign in to Kaggle, and
it saves the credentials for future runs — no manual file copying needed.

> **Fallback (if the interactive prompt doesn't work):**
> 1. Go to https://www.kaggle.com → **Settings** → **API** → **Create New Token**
> 2. This downloads `kaggle.json`
> 3. Place it at `C:\Users\<you>\.kaggle\kaggle.json` (Windows)
>    or `~/.kaggle/kaggle.json` (Mac/Linux)
> 4. Mac/Linux only: `chmod 600 ~/.kaggle/kaggle.json`

### 1c. GPU (optional — Part 3 only)

Part 3's XGBoost script auto-detects CUDA and falls back to CPU. For GPU:
- NVIDIA GPU with CUDA support
- CUDA toolkit ≥ 12.0 and matching drivers
- `xgboost` pip package with GPU support (standard pip install works if CUDA drivers are present)

**Not required.** CPU fallback is automatic.

## 6. Preprocess the dataset (Role 1)

```bash
# Windows
venv\Scripts\python.exe preprocessing.py

# Mac/Linux
venv/bin/python preprocessing.py
```

### What it does

1. Loads `data/raw/student_placement.csv` (5,000 rows × 18 columns)
2. Drops `student_id` (identifier only) and `salary_package_lpa` (target leakage)
3. Separates 15 features from target `placement_status`
4. Splits 80/20 stratified train/test (random_state=42)
5. Fits `ColumnTransformer` on training data only:
   - `StandardScaler` on 13 numerical features
   - `OneHotEncoder` on 2 categorical features (gender, extracurricular_activities)
6. Transforms both train and test sets (15 → 17 processed features)
7. Calculates class weights for imbalanced data (82.68% Not Placed, 17.32% Placed)

### Outputs produced

```
data/processed/train_processed.csv        ← 4000 rows × 18 columns (17 features + target)
data/processed/test_processed.csv         ← 1000 rows × 18 columns
data/processed/class_weights.csv          ← class → weight mapping
part2/models/preprocessor.joblib          ← fitted ColumnTransformer (used by API at runtime)
```

> **Critical:** `part2/models/preprocessor.joblib` is the canonical preprocessor.
> The live FastAPI backend loads this exact file at startup. Without it, the
> API starts in degraded mode and `/api/v1/predict` returns 503.

## 7. Train Part 2 models — Logistic Regression + Random Forest (Role 2)

> **Important:** all Part 2 scripts must be run from the **repo root** (not from inside `part2/`).
> The `run_pipeline.bat` handles this automatically.

### Option A — Run the full pipeline (Windows, recommended)

Double-click `part2\run_pipeline.bat` or run from the repo root:

```bash
part2\run_pipeline.bat
```

This runs the complete Part 2 pipeline in order:
1. `download_dataset.py` — download dataset (safe to re-run)
2. `preprocessing.py` — preprocess (regenerates processed CSVs)
3. `part2/logistic_regression_model.py` — train + evaluate Logistic Regression
4. `part2/random_forest_model.py` — train + evaluate Random Forest
5. `part2/model_comparison.py` — head-to-head comparison (depends on steps 3+4 producing both model `.joblib` files AND `logreg_metadata.csv` / `rf_metadata.csv`)
6. `part2/model_summary_report.py` — generate summary report (depends on steps 3+4+5)

### Option A2 — Run the full pipeline (Mac/Linux)

`run_pipeline.bat` is Windows-only. On Mac/Linux, run each step individually:

```bash
venv/bin/python preprocessing.py
venv/bin/python part2/logistic_regression_model.py
venv/bin/python part2/random_forest_model.py
venv/bin/python part2/model_comparison.py
venv/bin/python part2/model_summary_report.py
```

### Option B — Run only the minimum for the API

If you only need the backend API to work (skip evaluation plots):

```bash
# Windows
venv\Scripts\python.exe part2\random_forest_model.py

# Mac/Linux
venv/bin/python part2/random_forest_model.py
```

### Additional standalone script

`part2/hp_sensitivity_analysis.py` runs a hyperparameter sensitivity study
(underfitting → default → tuned → overfitting). It is **not** part of the
main pipeline and is **not** required for the API. Run it separately if needed:

```bash
venv\Scripts\python.exe part2\hp_sensitivity_analysis.py       # Windows
# venv/bin/python part2/hp_sensitivity_analysis.py             # Mac/Linux
```

Produces: `hp_sensitivity_logreg.png`, `hp_sensitivity_rf.png`,
`hp_sensitivity_combined.png`, `hp_sensitivity_report.txt` in `part2/model_results/`.

## 15. Troubleshooting

### `ModuleNotFoundError: No module named 'kagglehub'`

You are not using the venv Python. Prefix commands with `venv\Scripts\python.exe`
(Windows) or `venv/bin/python` (Mac/Linux), or activate the venv first.

### `FileNotFoundError: data/raw/student_placement.csv`

The dataset was not placed at the expected path. Re-read Section 5. Run
`download_dataset.py`, note the printed path, and copy the CSV manually.

### `[API] [FAIL] Artifact not found: ...preprocessor.joblib`

Run `preprocessing.py` first. It saves `preprocessor.joblib` to `part2/models/`.

### `[API] [FAIL] Artifact not found: ...random_forest_best.joblib`

Run `part2/random_forest_model.py` (or `part2\run_pipeline.bat`) to train
and save the Random Forest model.

### API starts but frontend shows "Cannot reach the prediction backend"

The backend must be running on `http://localhost:8000` before starting the
frontend. Check that `uvicorn` is running in another terminal and `/health`
returns `"healthy"`.

### `xgboost_model.py` prints "GPU not available, falling back to CPU"

Normal if you don't have an NVIDIA GPU with CUDA. Training will be slower
but produces identical results.

### `ERROR: preprocessing.py failed` from `run_pipeline.bat`

The batch file runs `preprocessing.py` from the repo root. If `data/raw/student_placement.csv`
is missing, this step fails. Download and place the dataset first (Section 5).

### Python version mismatch errors

If you see syntax errors or import failures, check `python --version`.
This project requires **Python 3.12**. Create the venv with the correct
interpreter:

```bash
py -3.12 -m venv venv        # Windows
python3.12 -m venv venv      # Mac/Linux
```
